# 独自全身骨格 v0.1 / 引継ぎ

作成日: 2026-10-23

## 目的と現在地
ユーザーの「全身に進めよう」に応じ、近位大腿骨だけの試作から全身の位置関係と13部位への移動を確認する独立ページへ拡張した。

- ページ: experiments/cleanroom-whole-body-v0.1.html
- 公開予定URL: https://s922h86hh8-tech.github.io/body-map-prototype/experiments/cleanroom-whole-body-v0.1.html
- 元アプリ、既存GLB、過去の大腿骨試作は保持。大腿骨詳細v0.4へリンクするが、そのメッシュを全身版へ結合していない。
- 全身の骨格配置のみ。筋・腱・靱帯・図鑑統合は未制作。完成した全身解剖モデルとは扱わない。

## 制作来歴・座標
第三者メッシュ、画像輪郭、スキャン座標、外部の形状生成コードは使用していない。HTML内のell/tube/bone/buildが独自の造形正本。球・楕円体、管、三角形の組合せ。寸法は今回の描画設計値で人体計測値ではない。

全身座標は+X身体右、+Y前、+Z上。近位大腿骨の「+X外側」は右側局所規約だったため、この全身座標と混同しない。両側形状はX反転で配置。正面では身体右が画面左。

頭蓋・下顎、頸椎7/胸椎12/腰椎5の模式椎体、左右12対の模式肋骨、胸骨、肩甲帯、寛骨/仙骨/尾骨、上肢/下肢、手/足を組み立てた。手根・足根は一括形状。363は描画部品数で骨数ではない。頭蓋骨の個別骨、椎骨突起、関節面、筋付着は未制作。寛骨も輪郭状の模式表現で解剖学的境界ではない。形状監査や専門家承認は未完了。

## UI
既存台帳の13部位を明示分類し、名称推測で分類しない。部位選択で表示を寄せる。両側/右/左、選択部位だけ表示、前/後/右/左、1本指回転・2本指拡縮、ボタンとキーボード操作。リセットは全身/両側/前。選択部位の説明と未制作項目を表示する。

Canvas2Dで3D頂点を回転・投影し、面を奥行き順で描画。WebGLを必要としない。これは物理的に正しい遮蔽やブラウザ互換性を保証するものではない。三角形の奥行きソートなので交差形状の描画には限界がある。部位クリックではなく部位ボタンで選択する。

## 検証・再現
node tools/cleanroom/check-whole-body-v0.1.cjs

Nodeと@napi-rs/canvasを使用。実際のHTMLのスクリプトをVM実行し、実Canvas2Dで正面と6部位をPNG描画、目視確認。24,434頂点/47,416三角形、面積0の三角形0、有限座標・インデックス範囲・左右の鏡像を検証。13部位×3左右条件、孤立表示、4方向、拡縮・リセット、pointer回転/ピンチの処理、描画領域幅320/390/1280を検証した。

これはブラウザDOMレイアウト・実タッチイベント・iPhone実機試験ではない。個別プリミティブは重なっており、全身を一つの閉じた多様体とする設計ではない。自己交差なしとは主張しない。
