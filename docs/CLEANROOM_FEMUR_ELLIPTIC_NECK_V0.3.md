# 楕円状頸部の独自模式試作：設計 v0.3（ページv0.4）
設計日：2026-10-22。実装前に設計値を記録。
対象ブランチ：cleanroom-pelvis-v0.1

## 目的
頸部を円形断面の管で近似している現行版から、楕円状の断面を表現できる方式へ進める。
Zhang et al. 2021（DOI10.1111/os.12914）の楕円状断面という定性的な照合を背景とする。比率・向き・座標を同論文から抽出しない。既存のメッシュ/図版を写さない。

## 今回独自に決める値
- 頸部管の既存両端、半径、骨頭中心、骨体軸、大転子と凹みの元パラメータを土台にする。
- 頸部管の軸に直交する平面へ+Z方向を投影して基準Uを作り、Vを軸とUの外積で作る。
- U方向の倍率1.12、V方向の倍率1/1.12。孤立した管の断面長短比は1.2544、倍率の積は1。
- 比率1.2544と方向は描画方式を検証するための設計値。標準寸法・標準角度・人体の個体差の代表値ではなく、採用承認も未了。
- 形状関数は異方的に座標変換した管の陰関数。最小倍率で値を調整するが、正確なユークリッド距離関数とは扱わない。平滑結合後の断面は理想楕円や同面積になるとは限らない。
- 着色は引き続き造形要素由来で、筋停止面ではない。

## 保存と検証
旧版を保全し、HTML v0.4、パラメータv0.3、glTF v0.3、生成コードと検証記録を新規保存する。
独立検証ページに未監査表示と旧版比較リンクを設ける。

ブラウザ/描画の結果とiPhone実機確認は区別。解剖学的採用は別途判断する。

## 実装・再検証（2026-10-23）
- 前回のリポジトリ保存が未確定だったため、保存前に形状・断面診断・描画を再実行。
- HTML v0.4、形状パラメータv0.3、保存glTF v0.3。21,448頂点/42,892三角形、閉じた1連結、境界/不正辺・面積0/尺度調整後極小面積三角形0。glTF出力でも同じ構造を確認。
- U/Vの単位長、相互および頸部管軸との直交、倍率積1、孤立した管の境界点を確認。
- 6方向、頸部選択時の斜め拡大、転子窩選択時の後内側拡大、リセットをNode VMのコールバックとして確認。ブラウザタッチ試験ではない。
- 91断面を再計算。中央50%のモーメント等価軸比1.25362（旧版1.00318）。頸部ラベル95%以上の条件は19–63%、最小面積サンプルは28%、面積494.86304描画単位²、軸比1.25144。
- その他の造形元パラメータが同じでも平滑結合のため隣接面は変化する。現行形状は解剖学的に未承認。
- 実HTMLのシェーダーをMesa OpenGL ES 3.2でオフスクリーン描画し、全体/後内側/内側を確認。
- Playwright試験コードは用意したがChromium本体の欠如で起動前に停止。ブラウザ試験合格と扱わない。iPhone/Safari実機も未確認。
