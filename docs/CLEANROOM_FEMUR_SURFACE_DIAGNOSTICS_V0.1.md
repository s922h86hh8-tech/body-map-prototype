# 生成表面の数値診断 v0.1
実施日：2026-10-22（日本時間）
対象：cleanroom-pelvis-v0.1／表示HTML v0.3／形状パラメータv0.2
状態：計算手順の実装・実行済み。解剖学的承認は保留。

## 今回進めたこと
造形アンカーだけを比べる段階から、実HTMLのbuildMesh()で生成した表面を計算する段階へ進めた。
骨頭への球の当てはめ、頸部/近位骨体の切断輪郭、転子窩を通る方向別プロファイルを実装した。
造形由来の区分や切断面を使うため、以下は独立した解剖学的ランドマーク抽出ではない。数値の単位はすべて無単位の描画値。mmではない。

再現コード：tools/cleanroom/measure-femur-surface-v0.1.cjs
結果：docs/validation/cleanroom-femur-surface-diagnostics-v0.1.json

実行：
```sh
node tools/cleanroom/measure-femur-surface-v0.1.cjs > docs/validation/cleanroom-femur-surface-diagnostics-v0.1.json
```
Node.js標準機能のみを使う。入力HTMLの既知SHA-256を確認し、形状が変わった場合は停止する。HTMLのMODELと保存JSONが一致することも確認する。既存HTML/JSON/glTFへの書き込みはしない。

## 計測方法と限界
| 対象 | 実装した方法 | 結果を使える範囲 |
| --- | --- | --- |
| 骨頭 | 造形ラベル1の頂点に代数的最小二乗球を当てはめる。造形球からの距離で選択を変え、感度も記録 | 頂点等重みの球らしさの診断。面積重みではなく、関節面の独立した同定でもない |
| 頸部/近位骨体 | 各造形管の25/50/75%点で、管軸に垂直な平面と全三角形の交線を求める。閉輪郭を分離し、周長重みの中心を計算 | 断面形状と造形軸の整合を見る。輪郭の中心は断面積重心でも臨床計測軸でもない |
| 複数輪郭 | 交線のグラフを連結成分に分け、次数2の閉輪郭を追跡。平面内で造形軸点を囲む輪郭を識別 | 輪郭を一括平均しない。囲む輪郭が一意でも、解剖学的に頸部だけとは保証しない |
| 転子窩 | 造形大転子中心から減算楕円体中心へ向かう方向を採用し、その線上で凹みあり/なしの陰関数への入口位置を比較。実メッシュの交点も別計算 | 一方向の造形変化を測る。最大深度、窩の面積、腱停止面としては扱わない |

平面と三角形の交差、連結輪郭、球当てはめ、線と三角形の交点を独自コードで計算した。平面が面と一致するような退化例を一般に処理する実装ではない。今回の断面は閉輪郭と各節点次数を確認した。
陰関数への入口は0.25描画単位の走査と二分探索で求める。この走査より細かな交差や接線接触を網羅する一般解法ではない。

## 計算結果
生成メッシュは21,512頂点、43,020三角形。既存の技術検証記録と一致。

### 骨頭の選択感度
| 選択範囲 | 頂点数 | 球半径 | 半径方向RMS残差 |
| --- | ---: | ---: | ---: |
| ラベル1全体 | 5,269 | 22.05485 | 0.18936 |
| 造形球から0.5以内に制限 | 5,031 | 22.00482 | 0.06199 |
| 造形球から1.0以内に制限 | 5,174 | 22.02996 | 0.12712 |

全体の推定中心は約[0.15078,-0.00540,-0.12057]。選択範囲で中心/残差が変わる。
造形球に近い頂点を選べば残差が減るのは選択条件の影響を含む。「残差が小さい＝人体の骨頭として正確」と判定しない。

### 断面
| 部位と管の位置 | 閉輪郭数 | 軸点を囲む輪郭の中心と造形軸の距離 |
| --- | ---: | ---: |
| 頸部25% | 1 | 0.17069 |
| 頸部50% | 1 | 0.00046 |
| 頸部75% | 2 | 8.85497 |
| 近位骨体25% | 1 | 0.00052 |
| 近位骨体50% | 1 | 0.00007 |
| 近位骨体75% | 1 | 0.00060 |

全断面で閉輪郭の節点次数は2。頸部75%は2輪郭となり、軸点を囲む一方の輪郭を選んでも中心が大きく変わる。
ここから言えるのは、単純に3断面の中心を結ぶ方法が現行の頸部管を安定して表すとはいえないこと。解剖学的な変形や造形不良の判定ではない。
近位骨体の中心が造形軸に近いことも、同じ管から作ったモデルの内部整合であり、人体の骨体軸としての承認にはならない。

### 転子窩方向別プロファイル
- 凹みなし/ありの陰関数入口の差：6.50658描画単位。
- 凹みありの最初のメッシュ交点と陰関数入口の差：約-0.06920描画単位。
- ラベル5の342頂点について範囲も保存した。このラベル境界は着色の生成規則であり、解剖学的な窩の開口や停止面の境界ではない。
- 差の大きさを精度の合格判定に使う閾値は未設定。格子化・平滑化と評価方向の影響を含む。

## 数値手順の検証
既知の中心/半径の球、三角形への命中/不命中、八面体の断面中心と周長、離れた2輪郭の識別、軸点を囲まない輪郭の除外、球の陰関数入口で、期待値と計算値が一致することを確認した。
これらは数値処理の検証であり、人体やiPhoneの試験ではない。
