# Clean-room 3D座標系 v0.1

日付: 2026-10-15  
状態: 座標の取り決めのみ確定。解剖ランドマーク座標・形状は未設定。

## 用途

独自試作で位置関係を記録するための内部座標規約。軸の決め方は制作上の約束であり、文献が定める人体計測値や骨の形状を意味しない。

## 右股関節のローカル座標

- 単位: millimeter (mm)
- +X: 外側（右股関節から身体正中線と反対方向）
- +Y: 前方（腹側）
- +Z: 上方（頭側）
- 座標系: 右手系
- 原点候補: 大腿骨頭の幾何学的中心。ただし、参照する骨モデルまたは監査済み点群を決めてから求める。現時点では原点の数値位置は未定。

## まだ定義しないこと

- 骨盤・大腿骨の点群、寸法、中心、角度。
- 梨状筋・内閉鎖筋・双子筋・大腿方形筋の任意ランドマークのX/Y/Z値。
- 左右反転を行うデータ変換式。符号規約を試作データで検証してから定義する。
- これらの軸を根拠に、資料にない筋腹の形や奥行きを推定すること。

## 適用ゲート

1. 使う骨性ランドマークを監査文書に列挙し、各点に根拠資料を紐づける。
2. 数値座標を置く場合、計測/参照データの来歴、ライセンス、単位変換、左右、基準点を記録する。
3. 数値のない関係は順序・隣接・通過の制約として保持し、捏造した数値へ変換しない。
4. 独自筋形状は未確定のまま。筋腹外形を作る際は、別途監査根拠と「模式」または「計測由来」の区別を明記する。
