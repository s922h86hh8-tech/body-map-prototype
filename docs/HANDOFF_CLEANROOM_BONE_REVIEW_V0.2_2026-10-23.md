## 変更
- 眼窩が後方・内側へ狭まる形、眼窩下の凹みと孔、頬骨弓の曲がりを調整。
- 下顎頭を横に広い形へ、筋突起を薄い三角形の面へ変更。下顎枝と体のつながりに斜線の概形を追加。
- 腰椎の上関節面は内側・後方へ向く凹面、下関節面は外側・前方へ向く凸面として近似。乳頭突起、幅広い棘突起、浅い椎弓根下の切れ込みを追加/改訂。
- 頭蓋3箇所、腰椎2箇所への部分拡大を追加。拡大状態を保って前版と切替可能。固定3図は拡大操作に影響されない。
- 新ページの旧版ボタンは直前の単体v0.1。全身v0.2ではない。旧版も同じ描画/カメラで比較。
- 右側面の方向を修正。+X身体右/+Y前/+Z上に対してカメラが+X側となるyaw=-π/2を使用。旧ページはyaw=+π/2で、実際には左側から見ていた。左右対称の造形だけではこのラベル誤りを視覚検出しにくかった。新ページでは座標の向きも検査する。

## 資料と造形値
Gray1918原著の既確認図188/190/92/93に加え、図157（上顎）、176/177（下顎の外面/内面）を目視。原著の上顎・下顎・腰椎の記述も照合。取得URL/ハッシュは docs/validation/cleanroom-bone-review-sources-v0.2.json。
各画像を校正済み同一標本の多方向画像とは扱わない。輪郭のトレース、抽出座標、スキャン、第三者メッシュは不使用。独自の陰関数/断面/曲線で制作。寸法・関節面の方向ベクトル・角度は任意の設計値であり、人体の測定値ではない。
図版の定性的照合は、独立した骨面監査や数値一致の証明ではない。筋付着表示、歯根・個別歯冠、骨厚、頭蓋底、咬合・顎関節面、レベル別腰椎や左右差は精密再現していない。

## 再現と検証範囲
python tools/cleanroom/build-bone-review-v0.2.py
node tools/cleanroom/check-bone-review-v0.2.cjs

Node / @napi-rs/canvas / Pythonが必要。旧単体v0.1 HTMLのSHA-256を固定して比較モデルを取り込み、新造形スクリプトを組み込む。生成物は単体HTMLで外部スクリプト/メッシュ不要。
- 有限座標、インデックス、面積、辺の数/方向、符号付き体積、連結数を検査。
- 最初の検査で腰椎に26頂点の孤立片を検出。椎弓根下の切れ込みを浅く/狭くし、再検査対象にした。孤立片を検査から除外していない。
- 2対象×2版、5方向、5部分拡大、固定図不変、同じ対象の旧/新切替で拡大維持、下顎/歯冠表示、回転/ピンチ/リセット、直近選択の優先をVMで検証。
- 実HTMLのCanvas2Dを@napi-rs/canvasで描画し、比較3方向と5部分の画像を目視。クラウドブラウザの試験は別途記録。
- 技術結果: docs/validation/cleanroom-bone-review-v0.2.json。画像: 同名-skull.jpg / -lumbar.jpg（上段v0.1、下段v0.2）、-details.jpg。

## 採用判断と残作業
単体の形状レビュー用。全身への採用は保留。既存本体・全身版・大腿骨詳細・第三者GLBは維持。
1. 公開HTMLのHTTP/ハッシュ一致、ブラウザ操作を別JSONへ記録。
2. ユーザーの形状比較、iPhone実機の生成待ち時間・タッチ・ボタン/固定図の確認。
3. 独立した解剖学資料または専門家による頭蓋/顎/腰椎の骨面監査。咬合・関節面・実寸を評価。自己交差の厳密検査も未実施。
4. 単体の採用判断後に全身モデルへ反映し、接続と全身体長比を再評価する。閉じたメッシュであることを解剖学的承認としない。
