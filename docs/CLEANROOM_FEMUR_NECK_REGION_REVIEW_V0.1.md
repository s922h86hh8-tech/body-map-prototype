# 頸部91断面の範囲・面積・形状診断 v0.2
日付：2026-10-22（日本時間）
対象：表示HTML v0.3／形状パラメータv0.2
作業ブランチ：cleanroom-pelvis-v0.1

## 進捗と判断
v0.1の3断面を91断面へ拡張し、輪郭の面積・面積重心・面積二次モーメントと、輪郭長に占める造形ラベルの割合を計算した。
現行の頸部近似は広い範囲でほぼ円形。後述の独立資料には楕円状断面の報告があり、円い管による単純化を今後の形状改訂の検討項目へ追加する。
ただし、現行の造形軸・選択範囲は文献の臨床測定法と異なるため、文献値へ直接合わせる採否判断はしない。

## 独立資料の確認
### Zhang et al. 2021
The Oval-like Cross-section of Femoral Neck Isthmus in Three-dimensional Morphological Analysis.
DOI：https://doi.org/10.1111/os.12914
取得先：https://onlinelibrary.wiley.com/doi/10.1111/os.12914
確認箇所：Reconstruction Method、Parameters of the FNI、Results、Limitations。

骨頭表面の球当てはめと同心球の交線から頸部方向を定め、その方向に連続断面を作り最小断面を評価している。200人のCT再構成を用い、頸部峡部の断面を楕円に近い形として報告。対象は50–85歳で、近位大腿骨骨折の診療集団から選択した資料であり、全年齢の唯一の標準形とは扱わない。
本試作は無単位のため、同論文のmm単位の球拡大量・走査間隔を移植できない。図版・メッシュ・輪郭を制作に取り込んでいない。

### Kang et al. 2005
An anatomic coordinate system of the femoral neck for highly reproducible BMD measurements using 3D QCT.
DOI：https://doi.org/10.1016/j.compmedimag.2005.05.002
記録：https://pubmed.ncbi.nlm.nih.gov/16143496/
確認範囲：検索取得で読めた原著要旨と出版社の方法抜粋。出版社への直接取得は403、PubMedの直接取得も本文が読めない応答だったため、全文を確認したとは記録しない。

要旨では、最小断面の中心に原点を置き、その断面に垂直な頸部軸を含む座標系を定め、二段階の最小化で求める方法を説明する。今回の固定方向走査とは異なる。要旨だけを根拠にその最適化を再現したとは扱わない。

## 実装した独自の診断手順
コード：tools/cleanroom/measure-femur-surface-v0.2.cjs
結果：docs/validation/cleanroom-femur-surface-diagnostics-v0.2.json
旧v0.1コード・結果は保全する。

1. 実HTMLのbuildMesh()から21,512頂点・43,020三角形を生成し、既知入力ハッシュと保存パラメータとの一致を確認。
2. 造形頸部管の始点から終点へ、5–95%を1%刻みで走査。各面の法線は造形管の方向に固定。1%は描画上のサンプリング規約であり、1mmではない。
3. 三角形との交線を閉輪郭へ分離し、造形軸点を囲む輪郭が一意である場合だけ候補にする。面と三角形が一致する退化例や閉じない輪郭は、無条件に候補へ採用しない。
4. 平面内の輪郭を多角形として積分し、面積・面積重心・面積二次モーメントを計算。固有値比の平方根を「モーメント等価軸比」とする。これは輪郭内の一様な面積分布に基づく診断値であり、論文の実測長短径や楕円当てはめそのものではない。
5. 交線各区間の中点へ実HTMLのpart()を適用し、区間長を重みとして造形ラベル割合を計算。これは距離由来の着色規則で、解剖学的な頸部/骨頭境界ではない。
6. 単一輪郭で頸部ラベル2の長さ割合が90/95/100%以上という3条件を比較する。閾値は独自の感度確認設定で、人体の採用基準ではない。浮動小数誤差には1e-12の許容を置く。

再現：
```sh
node tools/cleanroom/measure-femur-surface-v0.2.cjs > docs/validation/cleanroom-femur-surface-diagnostics-v0.2.json
```

## 計算結果
| 診断条件 | 該当した管の範囲 | 該当断面数 |
| --- | --- | ---: |
| 頸部ラベル90%以上 | 20–64% | 45 |
| 頸部ラベル95%以上 | 20–63% | 44 |
| 頸部ラベル100%（数値誤差許容あり） | 20–63% | 44 |

3条件とも、サンプル中の最小面積は管の28%にあり、面積494.68085描画単位の二乗、モーメント等価軸比1.00388だった。
これは固定方向・離散走査での計算候補であり、解剖学的な峡部の位置やmm²の測定結果ではない。方向を変える最適化は行っていない。

| 管の位置 | 候補輪郭の面積 | モーメント等価軸比 | 頸部ラベルの長さ割合 |
| --- | ---: | ---: | ---: |
| 10% | 752.39672 | 1.02982 | 0%（骨頭ラベル） |
| 28% | 494.68085 | 1.00388 | 約100% |
| 50% | 527.90493 | 1.00318 | 約100% |
| 60% | 550.64743 | 1.01955 | 約100% |
| 70% | 805.30173 | 1.68008 | 約61.1% |
| 75% | 1000.30571 | 1.68782 | 約45.7% |

70%では輪郭の約38.9%が大転子ラベル3、75%では大転子・転子窩ラベルも含む。付け根側で軸比が大きくなっても、それだけを頸部単独の楕円性の証明とは扱わない。
91断面で閉輪郭節点の次数は正常、三角形と切断面が一致する例は0。これは輪郭処理の成立であり、解剖学的な範囲判定の合格ではない。

## 数値検証
既知の長方形で面積・面積重心・モーメント等価軸比を確認し、頂点順の反転や平面内回転でも面積と軸比が変わらないことを確認した。八面体断面の既知面積も一致。
v0.1の球・三角形・多輪郭・陰関数入口の検証も継続し、実行は正常終了。

## 次の形状作業に渡す内容
- 20–63%を「解剖学的に監査済みの頸部」と命名しない。現行造形ラベルで他要素の混入が少ない計算範囲としてのみ使う。
- 円い管から楕円状の断面を表現できる方式への変更を候補にする。長短比・向き・位置ごとの変化は、独立資料と新しい模式試作で確認する。今回の文献から唯一の寸法や座標を推測しない。
- 現行の管軸を人体の軸に昇格させず、骨頭・頸部の範囲定義と測定方向の選択を継続監査する。
- 形状・公開ページの変更、iPhone実機試験、臨床/学習用への採用判断は今回行っていない。
