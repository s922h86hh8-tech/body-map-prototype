# 身体の地図｜設計台帳（Anatomy Master）

更新日: 2026-10-07  
対象: 3D Prototype 0.3 / branch `prototype-0.3`

このファイルは、画面には表示しない「身体の地図」の設計正本です。  
分類・名称・UI・データの判断を会話だけに残さず、今後の修正で方針が戻ったり混ざったりしないために使います。

## 1. この台帳の扱い

- **確定**: 現時点の設計として採用する。
- **暫定**: 現在は動作に使っているが、解剖学的な再監査が必要。
- **要確認**: iPhone実機または資料照合が終わるまで断定しない。
- コードと台帳が食い違った場合は、勝手にどちらかを正解にせず原因を確認する。
- iPhone実機表示とコードの想定が食い違った場合は、実機表示を優先して原因を調べる。

## 2. 基本設計

### 確定
- 現在の基準モデルは **全身骨格 + 全身解剖モデル**。
- 旧「右股関節・深層外旋筋群」部分モデルは、現在の標準UIから外す。
- 旧モデル用の「右寛骨」「右大腿骨」等の個別チェック欄は表示しない。
- 旧「骨だけ」「すべて」ボタンは表示しない。
- 一時的な「全身骨格テスト」「全身骨格筋」ボタンも標準UIから外す。
- 基本階層は **部位 → 層/区分 → 個別構造**。
- 全身に一律の「表層・中間層・深層」を当てはめない。部位ごとに適切な層分類を使う。

## 3. 部位分類

### 現在採用している部位
- 頭部・顔面
- 頸部
- 肩部
- 胸部
- 背部
- 腰部・腹部
- 殿部・骨盤
- 上腕
- 前腕
- 手
- 大腿
- 下腿
- 足

### 確定
- 頸部筋を頭部・顔面より優先して「頸部」へ分類する。
- `foot` を含む構造は「足」、`hand` を含む構造は「手」を優先する。
- 手足で同名になり得る構造は、部位文脈を先に判定してから名称を決める。
- 足背の短母趾伸筋は「足」に分類する。

### 要確認
- 現在の部位判定には正規表現による暫定分類が残る。
- 最終的には各構造を明示したマスターデータに移し、名称からの推測分類を減らす。

## 4. 層・区分

### 足：確定方針
足は一律3層ではなく、次の区分を使う。

- 足背
- 第1層
- 第2層
- 第3層
- 第4層
- 関連構造

現在の代表分類:
- 足背: 短母趾伸筋
- 第1層: 母趾外転筋、短趾屈筋、小趾外転筋
- 第2層: 足底方形筋、虫様筋
- 第3層: 短母趾屈筋、母趾内転筋、短小趾屈筋、小趾対立筋
- 第4層: 底側骨間筋
- 靱帯など筋以外は「関連構造」

### 手：暫定
手は現在、
- 表層
- 中間層
- 深層
- 関連構造

で表示している。

現在の方針:
- 虫様筋群: 中間層
- 母指対立筋、小指対立筋、母指内転筋、骨間筋群: 深層
- 筋以外の構造: 関連構造

**手の層分類は今後さらに解剖学的に監査する。**

### その他の部位：暫定
- 現在は主に「表層・中間層・深層」を使っている。
- 頸部、背部、前腕などは部位ごとに再監査する。
- 「すべての部位を3層にする」ことは確定ルールではない。

## 5. 名称ルール

### 確定
- 表示は日本語を基本とする。
- 左右は `左｜` / `右｜` で表示する。
- 手では「小指」、足では「小趾」を使い分ける。
- 母指 / 母趾も手足で使い分ける。
- 元データの raw mesh 名は内部識別用として保持し、表示名だけを置き換える。
- 頭・部・斜頭・横頭・浅頭など、意味のある部分名称は可能な限り消さない。

### 虫様筋
- 手: 左右それぞれ **「虫様筋群（手）」** として元データ上1構造ずつ。
- 足: 左右それぞれ **第1〜第4虫様筋**。合計8構造あること自体は元データ上正常。
- 「多数表示される＝重複」とは決めつけず、元データの構造数と照合する。

### 手足で特に区別する名称
手:
- 小指外転筋
- 短小指屈筋
- 小指対立筋
- 虫様筋群（手）
- 背側骨間筋群（手）
- 掌側骨間筋群（手）

足:
- 小趾外転筋
- 短小趾屈筋
- 小趾対立筋
- 第1〜第4虫様筋（足）
- 第1〜第3底側骨間筋（足）

## 6. 構造種別

### 現在の種別
- 筋
- 腱
- 靱帯
- 筋膜・腱膜
- 軟骨
- 支帯
- 骨間膜

### 確定方針
- 筋以外の構造を筋の層に無理に入れない。
- 必要に応じて「関連構造」へ分離する。
- 将来的には raw 名の正規表現判定ではなく、構造ごとのマスター属性にする。

## 7. 元データと監査

使用中の全身解剖データ:
- BodyExplorer由来の `anatomy.glb`
- BodyExplorer由来の `skeleton.glb`
- `mesh_mapping.json` の構造数: 467

### 実施済み
- 467構造と日本語辞書を機械照合し、辞書未対応 0件まで整理。
- ただし「辞書に引っかかる」ことと「正式名称・部位・層が完全に正しい」ことは別。
- 部位分類と層分類は引き続き監査する。

## 8. UIルール

### 確定
- iPhoneの片手操作を重視する。
- 固定中: 1本指で回転。モデル位置は動かさない。
- 固定解除: 1本指で移動。
- 回転ON/OFFを独立して切り替えられる。
- 十字移動ボタンを使用する。
- 表示パネルは右へしまい、右端タブから戻せる。
- 3D初期表示は、全身が縦画面に自然に収まる向き・カメラ位置を維持する。
- 2026-10-04〜05に確認できた全身の向き・初期フィットは、ユーザー実機確認済みの基準として扱う。

## 9. 未解決・要確認

- 手の層分類の詳細監査。
- 前腕の層分類監査。
- 頸部の層分類監査。
- 背部など残り部位の層分類監査。
- iPhoneで最新公開版の手・足・虫様筋表示を確認する。
- 日本語名称は、表示漏れ0とは別に正式名称・部位文脈・頭/部の表記を継続監査する。
- 最終公開・商用利用前に、BodyParts3D / Z-Anatomy のライセンス・帰属表示・ShareAlike条件を再確認する。

最終的には、各構造を名称推測ではなく次の属性で管理する。

```
raw_name
display_name_ja
side
region
layer
structure_type
status
source
notes
```

目標:
**マスターが正解 → 3D画面はマスターを読み込んで表示する**
