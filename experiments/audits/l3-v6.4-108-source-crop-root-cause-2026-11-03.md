# 『施術者からだの地図』L3 v6〜v6.4：椎弓根断面と元CT参照データの不合格原因の監査
作成日：2026-11-03 JST  
開発ブランチ：`l3-reference-method-evaluation-v1`  
**判定：測定手順の技術試験は進展したが、L3解剖学的合格は未達。LumASeの7数値領域を含む単一L3標本としての完全性は、今回の108マスク検査では認証できない。**

## 1. 対象の選定と資料
- 参照：LumASe、Zenodo 7181338、2022年公開。公開記載はCC BY 4.0。
- ZIP `L1-L5FineSegMix-663case.zip`、メタデータMD5 `baf6374a927e9591dbae3314570bdb1e`。
- ZIP中に`_L3_seg.nii.gz`で終わるファイル108件を、非圧縮ファイルサイズ昇順＋ファイル名で安定ソートしてindex0〜107とした。L3という標本レベルは元ファイル名に基づくもので、標本解剖そのものの独立再同定は未実施。
- オリジナル画像の6境界面に、対象数値クラスの陽性ボクセルが存在するかを直接確認。MPRの表示範囲とリサンプリングの影響を受けない。
- 数値1〜7と正式な骨部位名の完全対応表は一次資料で未確認。**数字の対応を推測しない。**

## 2. v6: 断面を複数調べる測定技術
- 仮の長軸2点に対し直交するMPRを0.5mm間隔で生成。
- 数値領域ごとに連結領域・サンプル面積・PCA楕円径の**数値的な代理指標**を取得。実物の椎弓根峡部幅・高さではない。
- 合成管の狭窄が認識でき、RAS/LPSにまたがる座標・出典SHA不一致・ラベル不在の条件を技術検査。
- 元L3実データ2件での**全骨中心を通る架空軸**では、全数値ラベルの採用可能なROIが0だった。
- 理由：架空軸が該当する数値領域を通っていないなどの選択・検出問題。人工軸の検査結果から骨の不合格寸法を主張しない。
- CI: https://github.com/s922h86hh8-tech/body-map-prototype/actions/runs/41585672549

## 3. v6.1: 数値領域そのものを通る架空軸に変更
- 各数値クラスの実際のラベル陽性ボクセルを通る**あくまで計算検証用の仮軸**を作成。
- 2実データ例で、1〜6の多くの断面で面積・楕円代理指標が取れた。一方、数値7では35.35mm幅のMPRが画面外に接して全断面を拒否。
- **ここでの成功はラベル領域計算の検査であり、解剖学的椎弓根軸の発見ではない。**
- CI: https://github.com/s922h86hh8-tech/body-map-prototype/actions/runs/41585980384

## 4. v6.2: 表示範囲を広げた場合の逆転
- MPR範囲35.35mm→70.35mm→100.5mmで数値2/7を検証。
- 数値2は両症例で画面外接触による拒否が緩和。
- 数値7は70.35mm時に**元CT切り出し境界への接触**が疑われ、100.5mm時は症例によって一部「受理」へ変化。拡大と同時にサンプリングピッチも0.35mmから0.5mmへ変化したため、見かけの受理は境界画素の見落としを含む可能性がある。
- **MPR画面上の部分ROIが受理されたことを、元画像の骨構造の完全性の証明に使用しない。**
- CI: https://github.com/s922h86hh8-tech/body-map-prototype/actions/runs/41586213438

## 5. v6.3: 元の3Dボクセル上で実際に境界を確認
- 元L3 index20とindex48の**数値7は、どちらも元データの画像境界Y-lowに接している**ことを確認。
- 数値2/3は、両例とも原画像の6境界面から離れていた。
- 数値6は、両例とも原画像の境界に接していた。
- 元画像境界へ陽性ラベルが接することは、欠損・切り出しのリスクであって、解剖学的な欠損そのものを証明するわけではない。
- CI: https://github.com/s922h86hh8-tech/body-map-prototype/actions/runs/41586449819

## 7. 根本原因と具体的な対処
**発見した原因**
1. 断面計測の前提として、実解剖学上の椎弓根軸・峡部が未確認。
2. 7数値クラスから解剖学的名称への公式の対応が未確認。
3. MPR画像範囲不足と画素ピッチにより、見かけ上の断面採否が変化することを確認。
4. 元CT由来の数値領域の画像切り出し境界への接触が広範囲で存在し、**LumASeの単一マスクを全L3の無欠損基準として採用できるだけの証拠が得られない。**

**対処**
- 既存L3とLumASeの学習・研究成果は保全する。LumASeを放棄するのではなく、7数値クラスの部位別比較研究に限定。
- L3全体形状の参照データは、新たに完全に写り、注釈されていることが確認できるCTへ切替検討。候補：**VerSe 2020**（公式論文では「fully visualized vertebrae」をマスク化、NIfTI、椎骨レベルIDの公式対応あり）。
- VerSe公式再配布ライセンスは**CC BY-SA 4.0**。商用利用自体は可能だが、改変・再配布時の継承条件はLumASeのCC BY 4.0と異なる。販売予定の教材へ取り込む前に対象ファイルと派生成果物の許諾・出典・再配布設計の検討が必須。
- CTSpine1Kは非商用条件があるため、今の段階で販売用の骨形状に直接利用しない。
- 元画像上の椎弓根軸と、L3の椎体・椎孔・上下関節面は独立監査が必要。文献根拠付きの医学的・教育用途の許容閾値はまだ定義していない。

**現時点の採否**
- v6.0〜v6.4：コード・一時データ検査の**技術成功**。
- LumASe由来のL3：**完全骨形状として未採用**。
- VerSe：**外部出典を確認した代替候補であり、まだダウンロード・実検査・採用はしていない**。
- L3解剖学教材：**未合格**。
