# 単体v0.7：顔面骨の形状修正

2026-10-24。ユーザーがv0.6の顔面骨の不自然さを指摘し、修正を依頼。表面の滑らかさと解剖学的な正確さを分けて扱う。

## 目的と範囲
眼窩周囲の厚い盛り上がりと頬骨/上顎の部品状の膨らみを減らし、鼻の開口部を修正する独自設計の形状試作。単体v0.7を追加し、v0.6と同一視点で比較できる。全身版への採用は保留。実寸モデルでも解剖学的承認済みモデルでもない。
公開先: https://s922h86hh8-tech.github.io/body-map-prototype/experiments/cleanroom-bone-review-v0.7.html

## 実装変更
- 眉上へ足していた管状の追加部品を除き、前頭部自体で眼窩上縁を形成。
- 前方へ突出していた眼窩床の厚み/張り出しを減らし、前縁の後方へ配置。
- 上顎の外形と頬骨の外形を広い範囲でなじませる。斜めに足していた頬骨下の管状部品と、独立した犬歯窩のくり抜きを除去。
- 鼻の入口は上部を狭く、下部を広くした丸みのある開口へ変更。鼻梁と下端の小突起も調整。
- v0.6と同じ抽出間隔/面の仕上げ/描画方式を使用。顔面の定義式を変更したので頭蓋の頂点数/接続は前版と異なる。
- 下顎、歯冠、腰椎は形状定義と仕上げとも維持。テストで新旧の頂点/面配列を照合する。
- 旧版頭蓋はv0.6の形状定義を閉じたスコープへ保持し、旧版の空洞照明も対応する式を使用。形状キャッシュは対象/版で分離。旧版選択時は頭蓋をもう一度生成するので初回待ちが増える。

## 技術検証と限界
再現:
```
python tools/cleanroom/build-bone-review-v0.7.py
node tools/cleanroom/check-bone-review-v0.7.cjs
```
入力HTML v0.6のSHA256を固定。2対象×2版の座標/辺方向/連結数/面積/体積、5方向、部分拡大、旧新切替、回転/ピンチ/表示復帰等を検査する。Canvas2Dの実描画で前後3方向/部分拡大/4倍比較を作成し目視する。結果はdocs/validation/cleanroom-bone-review-v0.7.jsonと同名-skull/-lumbar/-details/-enlarged.jpg。

技術検査は骨面精度の証明ではない。図との寸法や形の誤差を数値で評価していない。眼窩内部、頭蓋底、鼻腔内部、縫合、上顎洞/歯根、咬合、顎関節、骨面の厚さは未完成/未監査。自己交差の厳密検査、独立した解剖学監査、専門家承認、iPhone実機の描画/操作/初回負荷は未完了。外形を変更しても、教材として正確な状態に達したとは断定しない。既存の全身/大腿骨/アプリやGLBは変更しない。

公開HTTP/ハッシュ/ブラウザ操作は別記録cleanroom-bone-review-v0.7-hosted.jsonに保存する。
