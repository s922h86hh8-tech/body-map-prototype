# 大転子の骨面・形状試作 v0.2（表示ページ v0.3）

設計日: 2026-10-15 JST。初稿は形状実装前に記録。

## 今回の範囲

大転子内側の凹みと上内側縁を識別できる模式試作を作る。現在の骨頭・頸部・骨体の造形を土台として、追加部分の技術的な成立を確認する。筋の停止面、骨盤、筋形状はまだ追加しない。

## 確認した位置関係と来歴

- Gray / Carter, 1858, Wellcome Collection `wkyuvavb`, 印刷p.113 / Fig.88（右大腿骨後面）を閲覧。原本の外形と後面の関係を確認した。公式所蔵記録にPublic Domain Markの表示がある。画像・輪郭・頂点をアプリへ取り込まない。
- Philippon et al., 2014, DOI `10.1177/2325967114535188` の Superomedial Border と Obturator Externus を照合。大転子の前後端を結ぶ上内側縁と、後方頸部・大転子内側面の境界付近の陥凹という位置関係を使う。論文の図・写真・計測座標は使わない。

## 操作と保存

- 従来の前・後ろ・外側・斜めを保持し、内側・後内側を追加する。
- 全体表示と骨面の拡大を切り替える。リセットは全体・後ろの初期状態に戻す。
- 「転子窩（模式）」は凹みの表面を着色し、後内側からの拡大表示へ切り替える。着色を外閉鎖筋や深層5筋の停止面と同一視しない。
- ページv0.3、パラメータv0.2、glTF v0.2を新規ファイルに保存する。旧HTML・旧パラメータ・旧glTF・既存GLBは維持する。

## 検証の採用条件

一つの閉じた連結メッシュで、境界辺・非多様体辺・面積0の三角形がないこと。凹みの表面が実際に生成され、外面へ開き、骨頭・頸部と骨体を切り離さないこと。glTFの座標・法線・インデックス・向きが成立すること。追加した表示切替・リセットの処理と、実際の配信ページを確認する。

技術確認を通っても、骨面の曲率、位置・比率、形状精度、筋停止面の解剖学的な承認とは扱わない。新ページのiPhone実機は改めて確認する。

## 描画レビューでの調整

初期の描画値では凹みが頸部側へ広がりすぎたため、設計範囲を縮小し、減算の接合縁を平滑化した。最終的な値は上表に保存した。これは模式試作の造形判断であり、人体の正常寸法が確定したという意味ではない。

## 実装・技術確認の結果

- ページv0.3、形状パラメータv0.2、保存用glTF v0.2を生成した。
- 閉じた連結成分1、境界・非多様体辺0、面積0および尺度を考慮した極小面積の三角形0。頂点・三角形数は検証JSONに記録した。凹みを除いた同一形状との体積差と、凹み側を向く表面法線を確認した。
- 実際のHTML内の生成コードと制御コールバックをNode VMで実行した。6方向、転子窩選択による後内側・拡大への切替、リセットを確認した。ブラウザでのタッチ操作やDOMレイアウトをこのVM試験で確認したとは扱わない。
- HTMLの実際のシェーダーをMesaのオフスクリーンOpenGL ESでコンパイル・リンクし、全体、後内側拡大、内側拡大を描画した。後内側拡大で凹みと着色を目視確認した。これはブラウザ/WebGLやiPhone実機の試験ではない。
- iPhone録画で下端にブラウザの浮動バーが重なる場面があったため、新ページはモバイルで下余白を増やした。実機での改善は未確認。
