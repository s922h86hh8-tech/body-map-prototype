# 単体v0.8：監査後の眼窩・上顎・鼻腔概形の修正

2026-10-24。ユーザーが資料照合監査の結果を受けて修正を依頼。
公開先: https://s922h86hh8-tech.github.io/body-map-prototype/experiments/cleanroom-bone-review-v0.8.html

## 監査で確認した問題
- 眼窩の本来の四辺形を基調とする輪郭と、三角形の人工的なギザギザを区別する必要がある。「角張りを全てなくす」という判断は不適切。
- v0.7は眼窩壁/床が単純なくり抜きの概形、上顎の犬歯窩を除去した後の凹凸再構成が不足。鼻腔内の中隔/鼻甲介は未制作だった。
- 資料照合は独立した専門家の承認ではない。大きさ/厚さ/個体差との誤差は分からない。

## 今回の変更
1. 眼窩の断面を丸みのある多角形で定義。上壁・下壁・内側/外側壁を意識した断面を、後方・内方へ狭めてつなぐ。単純な丸穴への平滑化ではない。視神経管/眼窩裂、各構成骨の境界、壁厚の再現は今回も未完了。
2. 上顎前面の形状へ連続変位を与え、犬歯窩を外側の浅い凹み、犬歯隆起をその内側の縦の膨らみとして再構成。独立した球状の穴を掘る方式を使わない。切歯部の小さい凹みも追加。値は無単位の設計値で、実寸や測定された深さではない。
3. 鼻腔へ薄い中隔と、左右の側壁へ根付く湾曲した下鼻甲介の概形を追加。中隔の篩骨垂直板/鋤骨の境界は分節しない。中/上鼻甲介、鼻道、孔/管、鼻腔全体や上顎洞の内部は未制作。骨の厚さも検証していない。
4. 下顎・歯冠・腰椎、抽出間隔、仕上げ処理、操作はv0.7を維持。旧比較はv0.7を閉じたスコープで保持。同一視点/縮尺で比較。旧版初回切替は別途形状生成するため待ち時間がある。

## 根拠と制作方法
- OpenStax Anatomy and Physiology 2e 7.2 The Skull: https://openstax.org/books/anatomy-and-physiology-2e/pages/7-2-the-skull （眼窩の壁/床、後方へ狭まる構成、骨性鼻中隔/下鼻甲介）
- Gray 1918 上顎骨: https://anatomie.cosminpopa.ro/en/5b-2-the-maxill-upper-jaw/ （犬歯窩/犬歯隆起/眼窩下孔の位置関係）
- Gray 1918 図190/188の正面/側面図は前版から継続参照。
本文を再確認し定性的に独自の式を設計。画像/図の座標抽出、輪郭トレース、第三者メッシュ、CTスキャン等は使用しない。図や文章だけから壁の実寸・厚さを保証しない。

## 再現と検証
```
python tools/cleanroom/build-bone-review-v0.8.py
node tools/cleanroom/check-bone-review-v0.8.cjs
node tools/cleanroom/check-face-features-v0.8.cjs
```
入力v0.7HTMLのSHA256を固定。全体検査は座標/接続/辺方向/連結数/面積/体積、2対象×2版、5方向、部分拡大、切替・回転・ピンチ・復帰、固定図の不変、4倍比較/6倍上限を対象とする。実Canvas2D描画で比較画像を作る。

補足の特徴検査では中隔・左右の下鼻甲介・眼窩床/上壁を固体、左右の中隔と鼻甲介の間や鼻腔下部・奥行き3箇所の眼窩を空間として場の符号で確認。犬歯窩と隆起の設計上の変位方向も確認する。これは数点での式の検査であり、最終三角形の空間全体・鼻道の連通・人体精度の保証ではない。

結果: docs/validation/cleanroom-bone-review-v0.8.json、cleanroom-face-features-v0.8.json。
描画: 同名-skull/-lumbar/-details/-enlarged.jpg。公開配信/ブラウザ検証は-hosted.json。

## 検査結果
全体検査と特徴検査は完了。新頭蓋一式81,713頂点/163,322三角形、腰椎39,986/79,972。新各メッシュ1連結、境界/不正辺0、辺方向整合、面積0なし、正の符号付き体積。下顎/歯冠/腰椎の頂点座標と接続は旧v0.7と完全一致。特徴検査で左右の設計空間と固体の符号を確認した。実描画で前後3方向/部分拡大/4倍比較を確認したが、眼窩縁の人工的なギザギザは残る。
