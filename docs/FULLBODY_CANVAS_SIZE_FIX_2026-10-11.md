# 全身3Dの見切れ調査｜Retina表示サイズの修正（2026-10-11）

対象：`prototype-0.3/fullbody-bone-opacity-diagnostic-v0.5.html`
直前版：`fullbody-bone-opacity-diagnostic-v0.4.html`（保持）
適用範囲：検証用ページのみ。本体の`index.html`・元GLBは未変更。

## iPhone実機で確認したこと

- ユーザーから、「全身を中央に」を押しても見切れた人体位置が変わらなかったと報告された（2026-10-11）。
- 録画では人体の一部が画面右端に見切れ、骨・筋の表示切替や透明度変更はできていた。
- この事実を優先し、以前の「中央ボタンの動作は判断できない」という保留を修正する。ただし原因は実機テスト前のため未確定。

## コード調査で見つかった原因候補

- 従来の検証ページは `renderer.setPixelRatio(Math.min(devicePixelRatio,2))` で高解像度描画を行っていた。
- 一方、`resize()` は `renderer.setSize(w,h,false)` を実行し、canvasのCSS幅・高さを更新していなかった。
- CSS側にもキャンバスの表示幅を`#view`へ収める指定が不足していた。
- Retina画面などで、canvasの描画バッファ寸法と画面上のCSS表示寸法に不一致が生じてモデルが右へ寄り、見切れる原因になる可能性が高い。
- ただしこれが唯一の原因かは実機で未確定。

## 検証版v0.5の修正

1. `renderer.setSize(w,h,true)` を使い、描画バッファ更新に加えcanvasのCSSサイズも更新する。
2. `body.diag-only #view canvas{display:block;width:100%;height:100%}` を追加し、描画キャンバスを表示領域内に収める。
3. 0幅・0高さを避け、計測用表示に `canvas CSS幅 / #view CSS幅` を示す。
4. 既存の「全身を中央に」・A/B/C/D・骨透明度の比較機能を維持する。
